# Wykłady — indeks tematów

Zachowano aktualne PDF-y z katalogu `Wykład`. Nie przepisywano dużych slajdów w całości, bo pełnią funkcję materiałów referencyjnych i zawierają układ graficzny.

## Kolejność nauki

1. `0 Wprowadzenie.pdf` — organizacja kursu, podstawowe pojęcia i zaliczenie.
2. `1a Praca w linii poleceń.pdf` — terminal, powłoka, dokumentacja, podstawowe polecenia.
3. `1b Skrypty.pdf` — minimalne skrypty i automatyzacja pracy.
4. `2a Topologie.pdf` — linie, węzły, szyna, gwiazda, drzewo, pierścień.
5. `2b Model OSI.pdf` — warstwy, adresacja L2/L3 i porządkowanie problemów.
6. `2c Adresacja.pdf` — MAC, IPv4, IPv6, unicast, multicast, broadcast, CIDR.
7. `3b Protokoły.pdf` — ARP, RARP, ICMP, IP, DHCP, UDP, TCP.
8. `4 Porty Serwisy Monitorowanie.pdf` — porty, kanał wirtualny, usługi, monitorowanie ruchu.
9. `5 Trasowanie.pdf` — urządzenia siećiowe, tablice tras, routery, traceroute.
10. `6 Maszyny wirtualne.pdf` — VM i kontenery jako środowisko laboratoryjne.
11. `7 Sieci virtualne.pdf` — VLAN, VPN, tunele, izolacja.
12. `8 Serwisy.pdf` — DNS i inne podstawowe usługi.
13. `9 Media transmisyjne.pdf` — media przewodowe i bezprzewodowe, światłowody, złącza.
14. [`IPv6.pdf`](IPv6.pdf) oraz [`ipv6-privacy.md`](ipv6-privacy.md) i [`ipv6-privacy.pdf`](ipv6-privacy.pdf) — ściąga i notatka o prywatności IPv6.

PDF `9 Media transmisyjne.pdf` ma 30 stron i został sprawdzony przez `pdfinfo` oraz render przykładowych stron; jest materiałem slajdowym, dlatego zachowano go jako PDF zamiast przepisywać każdy slajd.
