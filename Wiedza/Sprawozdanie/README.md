# Sprawozdanie — zasady i szablony

## Zasady

- Pisz tylko o zakresie podanym w `cX/Cel-ćwiczenia.txt` albo w aktualnym `README.md` dla ćwiczenia.
- Preferowany format źródłowy to LaTeX (`.tex`), dopuszczalny jest też Markdown (`.md`).
- Źródła sprawozdania powinny być w katalogu `~/cX` na volcie.
- Katalog źródłowy nie powinien zawierać wygenerowanych PDF-ów, logów i śmieci budowania.
- Sprawozdanie ma być krótkie: zwykle 1 strona A4, maksymalnie 2.
- W nagłówku podaj autora, numer ćwiczenia i temat.
- Najlepszy układ: zadanie → minimalny dowód wykonania → krótki komentarz.

## Co powinien zawierać dowód

- polecenie lub skrypt,
- najkrótszy sensowny wynik,
- zrzut ruchu albo diagram, jeżeli jest wymagany,
- krótkie wyjaśnienie, co wynik potwierdza.

Szablony i przykłady LaTeX zachowano w tym katalogu, ale usunięto wygenerowane pliki `.aux`, `.log`, `.dvi`, `.toc` i podobne.
