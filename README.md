# LabSK — uporządkowana baza wiedzy

Ta baza jest przepisanym i uporządkowanym zbiorem materiałów z archiwum. Układ jest celowo prosty:

- [c1](c1/README.md) — praca w terminalu, SSH, podstawy Uniksa i przygotowanie środowiska.
- [c2](c2/README.md) — model OSI, interfejsy, adresacja warstwy 2 i 3, IPv4/IPv6 oraz analiza własnej sieći.
- [c3](c3/README.md) — IPv6 w praktyce, DHCP, ARP, ICMP oraz zrzuty ruchu w `tcpdump`, `tshark` i Wiresharku.
- [c4](c4/README.md) — DNS, mDNS, LLMNR, NBNS, trasowanie oraz maszyna Linux w Azure.
- [c5](c5/README.md) — VPS w chmurze, prywatna sieć administracyjna ZeroTier/Tailscale i automatyzacja skryptami.
- [c6](c6/README.md) — zapora, kontenery OCI, usługa w chmurze i podłączenie jej do sieći wirtualnej.
- [Wiedza](Wiedza/README.md) — notatki ogólne, wykłady, ściągi, narzędzia i materiały referencyjne.
- [Moze_potrzebne](Moze_potrzebne/README.md) — materiały potencjalnie przydatne, ale mniej pewne, historyczne, anglojęzyczne albo nieprzypisane bezpiecznie do konkretnego ćwiczenia.

Najlepiej zacząć od [README.md](README.md) w odpowiednim katalogu `cX`, a dopiero potem sięgać do plików źródłowych i załączników. Stare, powielone i techniczne śmieci zostały usunięte lub zastąpione czytelnymi notatkami. Szczegóły są w [RAPORT_CZYSZCZENIA.md](RAPORT_CZYSZCZENIA.md).
