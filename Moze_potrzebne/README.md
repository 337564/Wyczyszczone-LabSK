# Może potrzebne

Ten katalog zawiera materiały, których nie usunięto, bo mogą się przydać, ale nie zostały bezpiecznie włączone do głównej bazy wiedzy.

Trafiły tu przede wszystkim:

- projekty indywidualne i sprawozdania niezwiązane bezpośrednio z aktualnym przebiegiem ćwiczeń,
- anglojęzyczne materiały z Berkeley CS168,
- stare materiały z poprzednich lat, jeżeli nie były oczywistymi duplikatami aktualnych plików,
- pliki Office/DOC/PPTX, których nie trzeba było przekształcać do notatek,
- materiały o niejasnym przypisaniu do konkretnego ćwiczenia.

Nie jest to śmietnik: usunięto oczywiste pliki tymczasowe, skróty, cache i artefakty budowania. Jeśli czegoś brakuje, najpewniej było duplikatem albo plikiem technicznym bez wartości dydaktycznej.
